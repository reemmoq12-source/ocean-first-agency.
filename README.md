# Ocean First Digital Agency 🌊

مشروع  وتدريب عملي لواجهة أمامية (Front-End) لشركة رقمية متخصصة في الحلول البرمجية وتصميم الويب، يهدف إلى تقديم تجربة مستخدم تفاعلية، حديثة، ومتجاوبة تماماً مع جميع الأجهزة.
.

---

## 🚀 التقنيات المستخدمة (Tech Stack)
* **HTML5:** لبناء هيكل صفحات الويب ودلالاتها الصحيحة.
* **CSS3:** لتنسيق الألوان، تأثيرات الزجاج (Glassmorphism)، والتدرجات البصرية.
* **Bootstrap 5:** لتوفير نظام الشبكة المتجاوب (Grid System) والمكونات الجاهزة.
* **JavaScript (ES6+):** للتعامل مع الأحداث والتحقق من صحة المدخلات في النماذج (Form Validation).
* **FontAwesome:** لتوفير الأيقونات التفاعلية.

---

## ✨ مميزات المشروع
* **تصميم متجاوب (Responsive):** يتكيف بسلاسة مع كافة أحجام الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).
* **هوية بصرية حديثة:** اعتماد تدرجات لونية جذابة (Purple/Teal) مع تأثيرات تفاعلية (Hover Effects) على الأزرار والكروت.
* **نموذج تواصل تفاعلي:** مدعوم بالتحقق من صحة المدخلات عبر الجافاسكريبت.
* **تنظيم برعايَة Clean Code:** فصل منظم للملفات (`css/`, `js/`, `images/`).

## ⚙️ طريقة التشغيل محلياً على جهازك
إذا أردت تشغيل المشروع محلياً:
1. قم بتحميل أو استنساخ المستودع (Clone / Download ZIP).
2. افتح مجلد المشروع باستخدام محرر النصوص (مثل **VS Code**).
3. افتح ملف **`index.html`** مباشرة بواسطة أي متصفح ويب، أو استخدم إضافة **Live Server** للتشغيل الفوري.
